同梱スクリプト 2 本の完全な API と、譲れないルールの要約です。

## サブコマンド

| コマンド | 内容 |
|---|---|
| `/logo new <brief>` | ブリーフ → リファレンス調査 → 広いラウンド → ゲート → リファイン → ゲート |
| `/logo round <dir>` | 指定ディレクトリのコンタクトシートを再生成して配信 |
| `/logo refine <concept-id>` | そのコンセプトを起点にリファインラウンドから再開 |
| `/logo ship <dir>` | アウトラインを焼き込み、アセットを組み、配線し、確認 |

## 7 つの譲れないルール

スキップしたときの被害が大きい順に並んでいます。

1. **生成の前に実在するデザインを見る。** 何も見ずに生成すると、1 つの分布から *N* 個のサンプルが出るだけ
2. **提示の前に描画して自分で見る。** パスデータからマークは判断できない
3. **16px で判断する。** 塗りは生き残り、線は潰れ、ディテールは負債
4. **その人についての推測を作品に焼き込まない。** 名前の意味は、それを前提に作る前に尋ねる
5. **手書きの文字ではなく、実在の書体アウトラインを使う**
6. **色は理論ではなく比較で決める。** 単体では問題ない色同士が、隣り合うと喧嘩することがある
7. **すべてのゲートで選ぶのはユーザー。** 理由付きで推薦はする、決定はしない

## `gallery.mjs`

```bash
node SKILLS_DIR/scripts/gallery.mjs <dir> [--port 4599] [--title "Round 2"] [--no-serve]
```

`<dir>` 内のすべての `*.svg` を読み、隣に `index.html` を書き出して配信します。

| フラグ | 既定値 | 内容 |
|---|---|---|
| `--port` | `4599` | ローカルサーバーのポート |
| `--title` | ディレクトリ名 | ページ見出し |
| `--no-serve` | 無効 | シートを書き出して終了、サーバーは立てない |

終了コード：ディレクトリが存在しない、または SVG が 1 つもない場合は `1`、それ以外は `0`。

<Aside type="note" title="なぜ file:// ではなく配信するのか">
ヘッドレスブラウザは `file://` スキームをブロックします。静的サーバーは、エージェントが自分で作ったシートをスクリーンショットする唯一の方法です。そしてそのシートを見ることが、この手順の目的そのものです。
</Aside>

### `concepts.json`

任意。SVG と同じディレクトリに置きます。エントリがないファイルもファイル名をキーとして描画されます。

```json
[
  {
    "id": "c01",
    "name": "Aperture",
    "note": "隙間のあるリング。レンズにも読める",
    "group": "Editorial serif",
    "fixedColour": false
  }
]
```

| フィールド | 効果 |
|---|---|
| `id` | 拡張子を除いた SVG のファイル名と一致させる |
| `name` | id の後ろに表示。省略するとキャプションは id のみ |
| `note` | キャプション下の 1 行 |
| `group` | セクション見出し。セクションはこのファイルでグループが最初に現れた順に並ぶ |
| `fixedColour` | カードにタグを付ける。`true` は `currentColor` を継承せず配色が固定されている意味 |

意図的に配色を固定する場合を除き、コンセプトは `fill="currentColor"` を使ってください。シートのライト/ダーク切り替えで検証できます。

## `outline.py`

```bash
echo '[{"id":"word","font":"Fraunces.ttf","text":"oharu",
        "axes":{"wght":700,"WONK":1,"opsz":144}}]' \
  | LOGO_FONT_DIR=./.fonts uv run --with fonttools --with uharfbuzz \
    python SKILLS_DIR/scripts/outline.py
```

標準入力から JSON のジョブ配列を読み、標準出力に JSON を書きます。

**ジョブのフィールド：** `id`、`font`（`LOGO_FONT_DIR` 内のファイル名、または絶対パス）、`text`、可変フォント用の任意の `axes`、1000 単位空間での任意の `tracking`。

**結果のフィールド：** `d`（SVG の y 軸下向き空間に反転済み、em を 1000 単位に正規化済みのパスデータ）、`width`、`bbox`、`ascender`、`descender`、`capHeight`、`xHeight`。

`LOGO_FONT_DIR` の既定値は `.fonts` です。フォントは呼び出し側の責任です — サイズが大きくライセンスも伴うため、そのディレクトリに取得し、バージョン管理からは除外してください。

## ジオメトリの落とし穴

いずれも、書き留められる前に実際の時間を溶かしたものです。

**パス文字列を解析してバウンディングボックスを求めてはいけません。** `SVGPathPen` は座標を 1 つしか持たない `H`/`V` 短縮コマンドを出力します。数値が x,y の交互だと仮定したコードは、最初の水平・垂直セグメント以降のすべてのグリフで静かに誤った値を返します。クラッシュはせず、もっともらしい出力が出ます。`outline.py` がまさにこの理由で `BoundsPen` から `bbox` を返しています。それを使ってください。

**ロゴタイプより背の低いマークは、正方形に切り抜いても作れません。** 狭い画面用のバリアントがマーク単体で、そのマークがロゴタイプの字面高より低い場合、ロックアップ全体を正方形にクリップしても目的の形にはなりません。SVG を 2 つ出力し、CSS で切り替えてください。

**座標は整数に丸める** — em 1000 単位で。実際の表示サイズでは誤差は 1 ピクセルをはるかに下回り、パスデータは約 3 分の 1 小さくなります。

**外部ファイルの `favicon.svg` は `currentColor` を継承できません。** 継承元のコンテキストが存在しないためです。テーマ対応が必要なら、ファイル内に `prefers-color-scheme` ブロックを埋め込んでください。

## アクセシビリティ

マークは図版なので、アクセシブルネームは周囲のマークアップから与えます。SVG に文字列を複製するのではなく、既存の i18n 文字列を用いてリンク側に `aria-label` を置き、SVG 自体は `aria-hidden` にします。テキストのブランド名を置き換えた場合は、それが必要としていた CSS（`text-overflow`、`white-space`、フォントサイズ指定）も削除してください。もう適用されず、次に読む人を誤解させます。

## 再現性

焼き込まれたパスデータは人手では読めず保守もできません。コンポーネントのヘッダーに、アウトラインが生成物であること、再生成する正確なコマンド、元の書体とその軸設定、そしてロゴタイプの文字列が固定されていることを記載してください。

**生成物だけでなく、生成スクリプトをコミットしてください。** スクラッチディレクトリにある生成スクリプトは、存在しない生成スクリプトです。
